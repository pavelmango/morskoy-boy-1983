## 1. Легенда и Происхождение Артефакта (1983)

В 1983 году в закрытой лаборатории релятивистской баллистики и дальней космической связи **ОКБ «Импульс»** группа физиков-теоретиков и системных программистов адаптировала советский электромеханический игровой автомат **«Морской Бой»** под отечественную операционную систему **ПК-ДОС 1.04**.

В отличие от паркового аттракциона, тренажёр предназначался для отработки интуиции операторов релятивистского перехвата:
1. **Конечность скорости сигнала ($c_{\text{eff}}$):** Свет от корабля на горизонте идёт к перископу время $\Delta t_{\text{св}} = D / c_{\text{eff}}$. Оператор видит силуэт корабля там, где он находился в момент испускания фотонов, а не там, где он находится в лабораторный момент выстрела.
2. **Релятивистская диляция собственного времени торпеды ($\Delta\tau$):** Торпеда «Шквал-Р» движется со скоростью $v_t = \beta_t c$. Согласно специальной теории относительности Эйнштейна — Лоренца, бортовой хронометр торпеды замедляется относительно часов командира перископа:
   $$\Delta \tau_{\text{торп}} = \Delta t_{\text{лаб}} \sqrt{1 - \beta_t^2} = \frac{\Delta t_{\text{лаб}}}{\gamma_t}, \quad \gamma_t = \frac{1}{\sqrt{1 - (v_t/c)^2}}$$
3. **Лоренцево сокращение силуэта корабля:** Движущийся со скоростью $v_s = \beta_s c$ корабль сжимается вдоль линии горизонта в $\gamma_s$ раз:
   $$L = \frac{L_0}{\gamma_s} = L_0 \sqrt{1 - \beta_s^2}$$
4. **Релятивистский угол упреждения ($\Delta\varphi$):** Полное угловое смещение между видимым в перископе положением корабля и точкой встречи с торпедой:
   $$\Delta\varphi = \omega_s \left( \frac{D}{c_{\text{eff}}} + \frac{D}{\beta_t c_{\text{eff}}} \right) = \omega_s \frac{D}{c_{\text{eff}}} \left(1 + \frac{1}{\beta_t}\right)$$

## 2. Состав Дискеты 3.5" / 5.25" (`A:\`)

* [`index.html`](./index.html) — Автономный симулятор перископа ПЗ-83 с зелёным/янтарным люминофором П-31, звуковым синтезатором ВИ53 и бортовым вычислителем Лоренца (размер ~20 КБ, 0 внешних зависимостей).
* [`MORSKOY.BAS`](./MORSKOY.BAS) — Исходный код для **ПК-ДОС / MS-DOS QBasic / GW-BASIC** (текстово-псевдографический видеорежим 80×25, звук `SOUND`, расчёт $\gamma$-фактора и поправки упреждения).
* [`build_floppy.py`](./build_floppy.py) — Генератор точного 1.44 МБ FAT12-образа дискеты (`MORSKOY_1983_PKDOS.img`) для записи на реальную 3.5" дискету или запуска в эмуляторах QEMU / DOSBox / VirtualBox.

## 3. Как Запустить

1. **Мгновенный запуск (ЭЛТ-перископ):** Откройте [`index.html`](./index.html) в любом браузере.
2. **Сборка 1.44 МБ образа дискеты (`MORSKOY_1983_PKDOS.img`):**
   ```powershell
   python build_floppy.py
   ```
